# BeautyFinance Analytics — apresentação para portfólio

## Descrição curta

Projeto de análise financeira e comercial de uma empresa fictícia de
cosméticos. Desenvolvi a geração, o tratamento e a validação dos dados em
Python, análises em PostgreSQL/Supabase e um dashboard de cinco páginas
no Power BI para acompanhar receita, custos, margem, orçamento e previsão
de receita.

## Resultados que o projeto permite investigar

De janeiro a agosto de 2026, a empresa simulada apresentou receita líquida
de R$ 497.957,18 e margem bruta de 58,51%. A receita superou o orçamento
comparável em 3,76%, enquanto Supermercados ficou 4,80% abaixo da meta.
Para setembro a dezembro, a previsão de receita de R$ 317.686,24 ficou
6,38% abaixo do orçamento dos mesmos meses.

Esses resultados descrevem dados fictícios; não representam impacto obtido
em uma empresa real. A previsão usa o crescimento recente e o padrão mensal
do ano anterior, com limites documentados no README.

## Competências demonstradas

- Python, Pandas e NumPy para geração e tratamento de dados.
- SQL, PostgreSQL e Supabase para modelagem, views e análises.
- Power BI, modelo dimensional e DAX para indicadores e comparações.
- Validação de dados e documentação das regras e limitações.
- Git e GitHub para versionamento do projeto.
