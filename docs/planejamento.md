# BeautyFinance Analytics

## Objetivo

Desenvolver uma solução de análise financeira comercial para acompanhar vendas, custos, margem, orçamento e forecast de uma empresa fictícia do setor de cosméticos.

## Período analisado

- Histórico: janeiro de 2024 a dezembro de 2025
- Realizado: janeiro a agosto de 2026
- Orçamento e forecast: setembro a dezembro de 2026

## Principais análises

- Receita líquida
- Custo total
- Margem bruta
- Margem percentual
- Orçamento versus realizado
- Crescimento mensal
- Crescimento anual
- Ticket médio
- Forecast

## Ferramentas

- Python

- SQL
- PostgreSQL
- Supabase
- Power BI
- Excel

- GitHub

Todos os dados, produtos, marcas e resultados utilizados neste projeto são fictícios e foram criados exclusivamente para fins educacionais e de portfólio.
