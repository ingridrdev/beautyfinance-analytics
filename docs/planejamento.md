# BeautyFinance Analytics

## Objetivo

Desenvolver uma solução de análise financeira comercial para acompanhar vendas, custos, margem, orçamento e forecast de uma empresa fictícia do setor de cosméticos.

## Período analisado

- Histórico: janeiro de 2024 a dezembro de 2025
- Realizado: janeiro a agosto de 2026
- Orçamento: janeiro de 2024 a dezembro de 2026
- Forecast de receita: setembro a dezembro de 2026

## Principais análises

- Receita líquida
- Custo total
- Margem bruta
- Margem percentual
- Orçamento versus realizado
- Crescimento mensal
- Crescimento anual
- Ticket médio
- Forecast

## Ferramentas

- Python
- Pandas
- SQL
- PostgreSQL
- Supabase
- Power BI
- Git
- GitHub

## Entrega para o portfólio

Implementados: geração, tratamento e validação de dados em Python;
tabelas, views e análises em PostgreSQL/Supabase; modelo dimensional e
cinco páginas no Power BI. O README apresenta resultados, capturas das
cinco páginas, instruções de reprodução e limites do forecast.

Análise complementar em Excel preparada em excel/beautyfinance_analise.xlsx,
com fórmulas e gráficos recalculados no Excel e conferência visual concluída
pela usuária em 12/11/2026. A versão atual conclui as entregas previstas de
Python, SQL, Power BI e Excel.
Cloudflare Pages não faz parte da entrega atual. As evidências e os limites da
validação estão em [revisao_dashboard_powerbi.md](revisao_dashboard_powerbi.md).

## Observação

Todos os dados, produtos, marcas e resultados utilizados neste projeto são fictícios e foram criados exclusivamente para fins educacionais e de portfólio.
