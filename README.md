# BeautyFinance Analytics

Projeto de análise financeira comercial desenvolvido para acompanhar vendas, custos, margem, orçamento e forecast de uma empresa fictícia do setor de cosméticos.

## Objetivo

Transformar dados de vendas em informações que ajudem a identificar o desempenho de produtos, marcas, canais e regiões, além de comparar os resultados realizados com o orçamento da empresa.

## Tecnologias

- Python
- Pandas
- SQL
- PostgreSQL
- Supabase
- Power BI
- Excel
- Git e GitHub

## Análises previstas

- Receita bruta e líquida
- Custos e margem bruta
- Margem percentual
- Orçamento versus realizado
- Crescimento mensal e anual
- Desempenho por produto e marca
- Desempenho por canal e região
- Forecast de receita
